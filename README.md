# Cash Panet Android App (`phindu-cyber/cp-apk`)

Full-screen Android mobile app for **[Cash Panet](https://cashpanet.app/)**.

## Features
- Launch splash screen and adaptive launcher icon featuring the official Cash Panet coin emblem (`#026134`)
- Full-screen mobile layout matching `https://cashpanet.app/`
- Persistent login cookies & payment checkout support
- Zero-permission Android Photo Picker & document upload support for task proof screenshots
- System back gesture navigation (including SPA history transitions)
- External social app launching & `cashpanet.app` deep-link handling
